# Investment Method Packs

Method packs apply different research processes to the same portfolio, thesis,
evidence, provenance, analysis, and authorization substrate. They do not replace
the calculation engines, alter supplied assumptions silently, write a ledger,
or execute an action.

Available packs are Core, Thorp, Mauboussin, Contrarian Filings, and Committee.
Use `capital method list`, `capital method run`, or `capital method committee`.
Analyze-position accepts `--method`; Core is the default.
