# Private-data policy

This cloud repository contains no personal inputs or generated research outputs. Keep all user-supplied context in an explicit authorized private directory outside source, bundle and Git checkouts. Private directories, credentials, raw books, portfolios, reports and logs never belong in public tests, fixtures or artifacts. Synthetic public fixtures are distinctly labeled.

Bootstrap selects only public asset roots and rejects private path segments and sentinels. Host upload destinations, retention, account permission, telemetry and support access require separate review. A repository code check cannot establish platform-wide noncollection.
