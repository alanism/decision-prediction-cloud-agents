# X/Twitter Evidence

Local X/Twitter batches model narrative velocity, influential claims, reflexivity, crowding, and noise. Deterministic metrics include directional counts and ratios, engagement-weighted direction, author diversity, duplicate claims, recency, and credibility weighting.

Modeled metrics include narrative momentum, crowding risk, noise penalty, and evidence weight. A social signal cannot directly alter Kelly inputs. It can contribute to a bounded belief update and a pending assumption proposal after the user verifies or corrects the source data.
