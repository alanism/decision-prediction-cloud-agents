# System boundary

Capital Decision Lab is a vendored deterministic research engine with a separate cloud adapter. It accepts explicit files and user-directed source queries, validates contained paths, separates input classes, and produces machine-readable results whose semantic values are provenance-labeled evidence atoms.

The workflow includes deterministic calculations, seeded modeled ranges, evidence connectors, bounded belief updates, model health, model-implied recommendations, hash-bound authorization validation, and atomic local ledger append. Network and browser access are confined to connector capabilities with retrieval provenance. It contains no transaction execution or model-created financial facts.
