# Evidence Intelligence

The evidence layer turns user-verified local source material into bounded inputs for capital research. Polymarket contributes event probabilities and volume, X/Twitter contributes narrative velocity and influential claims, and Reddit contributes community conviction, disagreement, and retail psychology.

The flow is local and explicit:

1. capture or paste source material locally;
2. structure and verify or correct extracted values;
3. calculate source-specific signals;
4. synthesize sources without hiding contradictions;
5. map evidence through a thesis sensitivity rule;
6. produce a bounded Bayesian update;
7. create a pending assumption-update proposal;
8. apply the update only after explicit approval.

The tool does not retrieve live data, scrape sites, execute trades, connect to accounts, or guarantee outcomes.
