# Shared cloud host contract

The bundled Python engine and adapter need a generic shell and explicit private filesystem destination. Every optional host capability must be detected and authorized independently: public research, extraction, human confirmation, image generation, actual image inspection, browser review, private delivery and scheduler.

host-capabilities.json names required receipts; it does not assert a provider API exists. doctor reports implemented filesystem/Python scope and unavailable host-native capabilities. Persist immutable artifacts and hashes; report platform retention/durability and recipient-access limits truthfully. Never infer account permissions from a tool name.
