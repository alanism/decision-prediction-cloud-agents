# HTML report guide

Default output is a self-contained HTML reading edition, with inline SVG for deterministic charts and an actual embedded PNG for the final accepted sketchnote. Include usable no-JavaScript tables and text alternatives. Keep financial calculations in the engine and render validated results without recomputation.

The stock template is a design scaffold, not completed evidence. Populate only validated inputs; keep unavailable sections explicit. Current policy supersedes historical sample verdict or sizing language. Source/audit navigation precedes strategy and final image.

A future optional Data Visualization Engineer role may select D3 for substantial 2D interaction and Three.js only for meaningful 3D exploration. Both must consume the same validated chart data and preserve static SVG/table fallbacks. This is a planned architecture note, not implemented dependencies or approved scope expansion.

Test actual browser layout, keyboard and repeated/reset flows, downloads, printing and assistive behavior before declaring visual acceptance. Mock-DOM tests do not close this gate.
