# Capital research

Start with the research question and available evidence, not a required portfolio upload. Optional private context needs an authorized destination. Separate observations, assumptions, calculations, models and forecasts.

Use actual available host research/extraction tools; preserve source URL or artifact hash, reference/publication/retrieval time, extraction confidence, verification status and limitations. Screenshots and OCR need real confirmation before verified use. Missing connectors return unavailable with reasons; do not claim APIs exist because a schema names them.

Validate case JSON, retain pending assumptions, and run bundled calculations using portable.py analyze/compare. Apply only verified thesis-specific Bayesian sensitivity updates; imported labels are not a confirmation event. Preserve convexity, hypothetical Kelly, margin stress and simulation limits. Report business evidence, competing interpretations, hypothetical outcomes and uncertainty. Do not turn model results into personal exposure instructions.

Upstream decision/recommendation contracts remain vendored for compatibility. Their names do not override educational policy; the cloud adapter does not expose recommendations, confirmation, ledger recording or transactions.
